Native, no detour

No ghost display, no copied frames. FineDisplay switches to a row that is already in macOS's own mode table. The desktop renders at 2×, the GPU scales to the panel. The same mechanism your MacBook's built-in Retina display uses.

Remembers

Your choice is stored per display. When you replug the display or the Mac wakes, FineDisplay re-applies it. Launch at login is optional.

How it works

Every display has a mode table inside WindowServer. For a 2560×1600 panel macOS generates modes such as 1920×1200 @2x and 2048×1280 @2x, then stamps them with kDisplayModeValidForMirroringFlag and never returns them from the public API. That is why System Settings stops at the panel size. The panel can do it; the cut-off is Apple's choice.

FineDisplay reads the full table with WindowServer's own calls (SkyLight CGSGetDisplayModeDescriptionOfLength) and switches with CGSConfigureDisplayMode. WindowServer accepts it. Everything after that is the standard macOS Retina pipeline. Apple's own override file for the 13" MacBook Air (same 2560×1600 panel) lists the same resolutions with the same flags.

Full investigation log: docs/how-it-works.md

Plain talk

  • It uses private API. Apple can change it. The app checks the symbols at launch; if they are gone it refuses to run and leaves your display alone.
  • It only enables modes that exist. If macOS did not generate hidden HiDPI modes for a display, FineDisplay cannot invent them. If finedisplay list shows no ★, BetterDisplay's virtual-display route is still an option.
  • It costs GPU. Rendering 4096×2560 is not free. Apple Silicon does not notice; old Intel GPUs may stutter.
  • If you change the mode in System Settings that wins until the next reconnect. Pick the mode in FineDisplay to make it stick.

Install

  1. Download FineDisplay-1.0.0.zip, unzip, move FineDisplay.app to Applications.
  2. Open it. If macOS says it "cannot verify" the app: System Settings → Privacy & Security, scroll down, Open Anyway.
  3. Click the monitor icon in the menu bar. Pick a ★ HiDPI mode for your external display. Done.

Command line: inside the app at FineDisplay.app/Contents/Resources/bin/finedisplay, or as a separate zip: finedisplay-cli-1.0.0.zip

finedisplay list                 # displays and modes; ★ = hidden HiDPI
finedisplay set 2 1920x1200      # looks like 1920×1200, rendered at 3840×2400
finedisplay set 2 2048x1280 --hz 60
finedisplay apply                # re-apply saved choices now

Build from source:

git clone https://github.com/ofbakirci/finedisplay
